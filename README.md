Site institucional desenvolvido para a academia **Semear Fitness**, com foco em simplicidade, desempenho e presença digital 🌱

---

## 🌐 Sobre o Projeto
Este projeto foi criado utilizando **HTML puro**, **CSS** e **JS**, sem frameworks ou bibliotecas externas.
O objetivo é oferecer um site leve, rápido e funcional para uma academia local.

---

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3 (com Custom Properties)
- JavaScript (ES6+, IntersectionObserver API)
- GitHub Pages (hospedagem)

---
